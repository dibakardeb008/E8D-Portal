E8D Portal prototype

A front-end walkthrough of every 8D discipline, for the Power Apps + SharePoint build. Type into any field: the values carry across pages so the flow can be demonstrated end to end. Nothing is saved anywhere except this browser.

Stages

    How to read the prototype

    • Header + Issue Detail panel are the same on every stage; only Stage Detail changes.
    • Discipline dots: stage you are viewing, current stage of the 8D, completed. Any stage can be opened at any time.
    • Next Stage on the current stage moves the 8D forward. On an earlier stage it only navigates.
    • Submit on D3A / D5A / D7A simulates the 8D Manager approval. Close 8D on D8 closes the record.
    • D7 & D7A are only active when D5 › Systemic action needed? = Yes; otherwise they are greyed out and skipped.
    • 8D Manager (D1) is mandatory: Next Stage is blocked until it is filled.
    • Fields showing options separated by “/” are dropdowns; other grey text is a hint that disappears when typing.
    • Dev notes (top-right on each stage) shows field types, SharePoint column names and logic for the developer.

    Issue Detail panel

    • Status (Open / Closed) and Current Stage (D#): system generated, read-only.
    • Shown on every stage: 8D Leader, Project Number, Project Name, Customer, Windchill Link, Attachments, Notes.
    • Notes work as an event log: each note is added with date/time, stage and author, and is locked once added – no edits or deletions.
    • Generate Report: button placeholder only in this phase.
