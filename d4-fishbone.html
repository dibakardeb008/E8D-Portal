Interactive Fish Bone.
  • Seven bones: Design, Man, Machine, Material (top) / Method, Measurement, Mother Nature (bottom). Design is added to the classic 6M because these are engineering-development failures; it lines up with D5 “Problem source = Design” and the DFMEA questions in D2 / D4. Each bone starts with Hypothesis 1 and grows as hypotheses are added.
  • Each hypothesis has a rib with a +/− button that opens or collapses its actions card. On a new 8D each bone shows Hypothesis 1 with its card open; added hypotheses open automatically; all others start collapsed and show “x actions · y results filled”.
  • “Expand all” / “Collapse all” open or close every actions card at once.
  • Card starts with Action 1 + Result 1. “+ Add action” adds a new action with one result; “+ Add result” adds more results under that action. Only the last action / result can be removed.
  • Data model: hypothesis → actions → results, e.g. child lists E8D_FishboneAction (hypothesis ID, Action No, Action) and E8D_FishboneResult (action ID, Result No, Result), or one table with Action No + Result No.
  • Fish head shows the D2 Problem Statement (read-only).
  • Same data as the form layout (E8D_Fishbone: one row per hypothesis), so both views can coexist.
  • Power Apps: easiest as a fixed fishbone background with a vertical gallery per bone; a fully drawn, growing diagram needs an SVG built in formulas (advanced).
  • Below ~760px wide the diagram switches to stacked cards.
