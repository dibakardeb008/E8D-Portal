D6 – Validation of PCA.
  • One card per corrective action from D5, pre-filled and read-only. To add or change a corrective action, go back to D5.
  • “Steps taken to validate” is stored against each corrective action (same row in E8D_CorrectiveActions).
  • D5 verifies by analysis (FEA, tolerance stacks); D6 validates by test.
  • If the failure is not resolved (“No”), anyone can start a new revision: D4–D6 of the current revision are archived read-only, the new revision is pre-filled from it and the 8D returns to D4. D0–D3 are not touched. Store a Revision number on every D4–D6 record.
